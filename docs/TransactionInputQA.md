# Transaction Input QA

거래입력 화면 수정 시 아래 항목을 기준으로 브라우저 QA를 수행한다.

## 신규

- [ ] 거래입력 페이지 진입이 정상 동작한다.
- [ ] 신규 진입 시 상세모달이 정상 오픈된다.
- [ ] 초기 포커스가 의도한 입력 위치에 들어간다.
- [ ] 거래내역 Grid가 빈 기본 행으로 초기화된다.
- [ ] 거래정산 Grid가 기본 상태로 초기화된다.

## 상세

- [ ] 목록에서 기존 거래를 선택해 상세모달을 열 수 있다.
- [ ] 헤더 필드가 저장값과 동일하게 표시된다.
- [ ] 거래내역 Grid 행 수와 값이 저장값과 동일하다.
- [ ] 거래정산 Grid 행 수와 값이 저장값과 동일하다.
- [ ] 첨부파일 목록이 저장값과 동일하다.
- [ ] 연결 전표 요약이 정상 표시된다.

## 수정

- [ ] 헤더 필드 수정 후 저장이 정상 동작한다.
- [ ] 거래내역 셀 수정 후 저장이 정상 동작한다.
- [ ] 거래정산 셀 수정 후 저장이 정상 동작한다.
- [ ] 저장 후 재조회 시 수정값이 유지된다.

## 삭제

- [ ] 목록 삭제 버튼이 정상 동작한다.
- [ ] 삭제 후 목록에서 항목이 사라진다.
- [ ] 삭제된 항목이 휴지통에 표시된다.

## 복구

- [ ] 휴지통 목록 조회가 정상 동작한다.
- [ ] 단건 복구가 정상 동작한다.
- [ ] 다건 복구가 정상 동작한다.
- [ ] 전체 복구가 정상 동작한다.

## 컬럼너비

- [ ] 거래내역 Grid 컬럼 너비 변경이 정상 동작한다.
- [ ] 모달 재오픈 후 거래내역 Grid 컬럼 너비가 복원된다.
- [ ] 거래정산 Grid 컬럼 너비 변경이 정상 동작한다.
- [ ] 모달 재오픈 후 거래정산 Grid 컬럼 너비가 복원된다.

## 키보드

- [ ] Enter 이동이 정상 동작한다.
- [ ] Tab 이동이 정상 동작한다.
- [ ] Shift+Tab 이동이 정상 동작한다.
- [ ] 방향키 이동이 정상 동작한다.
- [ ] F2 편집 시작이 정상 동작한다.
- [ ] Ctrl+Enter 편집 시작이 정상 동작한다.
- [ ] ESC 편집 취소가 정상 동작한다.
- [ ] Delete 셀 값 삭제가 정상 동작한다.
- [ ] Ctrl+C 복사가 정상 동작한다.
- [ ] Ctrl+V 붙여넣기가 정상 동작한다.

## AG Grid

- [ ] 거래내역 Grid 행 추가가 정상 동작한다.
- [ ] 거래내역 Grid 행 삭제가 정상 동작한다.
- [ ] 거래정산 Grid 행 추가가 정상 동작한다.
- [ ] 거래정산 Grid 행 삭제가 정상 동작한다.
- [ ] 컬럼 리사이즈 후 레이아웃 깨짐이 없다.
- [ ] 스크롤 시 헤더와 본문 정렬이 유지된다.

## Select2

- [ ] 거래처 검색이 정상 동작한다.
- [ ] 프로젝트 검색이 정상 동작한다.
- [ ] 계좌 검색이 정상 동작한다.
- [ ] 카드 검색이 정상 동작한다.
- [ ] 팀 검색이 정상 동작한다.
- [ ] 직원 검색이 정상 동작한다.
- [ ] 모달 닫힘 시 포커스 경고가 발생하지 않는다.
- [ ] `aria-hidden` 관련 콘솔 경고가 발생하지 않는다.

## 파일첨부

- [ ] 파일 선택 업로드가 정상 동작한다.
- [ ] 드래그앤드롭 업로드가 정상 동작한다.
- [ ] 파일 순서 변경이 정상 동작한다.
- [ ] 파일 삭제가 정상 동작한다.
- [ ] 저장 후 파일이 유지된다.
- [ ] 상세 재오픈 후 파일 목록이 저장값과 동일하다.

## 거래정산

- [ ] 헤더 기준 정산 표시가 정상 동작한다.
- [ ] 항목 기준 정산 전환이 정상 동작한다.
- [ ] 거래내역 선택 변경 시 정산 대상이 동기화된다.
- [ ] 정산 합계가 정상 반영된다.

## Console Error

- [ ] 신규 진입 중 Console Error가 0건이다.
- [ ] 상세 진입 중 Console Error가 0건이다.
- [ ] 저장 후 Console Error가 0건이다.
- [ ] 삭제 후 Console Error가 0건이다.
- [ ] 복구 후 Console Error가 0건이다.
- [ ] Select2 열기/닫기 중 Console Error가 0건이다.
- [ ] AG Grid 편집/리사이즈 중 Console Error가 0건이다.
