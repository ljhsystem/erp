# Ledger AG Grid Migration

## Decision

ERP 입력성 그리드는 AG Grid Community를 표준으로 사용한다.

조회/목록 화면은 DataTables를 유지하고, 거래/전표/분개처럼 셀 편집과 행 추가/삭제가 필요한 입력 화면은 AG Grid 입력 어댑터를 사용한다. Enterprise 전용 기능이 필요한 경우에는 별도로 판단한다.

## Rules

- 생성센터 모달과 거래입력 모달의 거래내역은 같은 AG Grid 입력 프로세스를 따른다.
- 라인유형, 단위, 통화처럼 기준정보에 있는 값은 코드 목록에서 가져온다.
- 선택 항목은 필수 검증에 포함하지 않는다.
- 데이터테이블과 모달은 같은 최종 검증 결과를 사용한다.
- 이전 그리드 라이브러리의 CDN, 공통 파일, CSS 선택자, DOM id, 변수명 잔재를 남기지 않는다.
