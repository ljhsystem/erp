# 법정기준 공식자료 전수 감사

## 원칙

- 적용기간은 회사 운영기간이 아니라 법정기준의 실제 효력기간이다.
- 값과 Source는 공식 1차 자료로 확인된 범위만 등록하며 추정값은 등록하지 않는다.
- 운영 반영은 `StatutoryStandardService`와 System Actor를 사용한다.
- DB는 `system_statutory_standards`, `system_statutory_standard_sources` 2테이블을 유지한다.

## 2026-08-12 감사 결과

- 13개 활성 Type의 기간·Source 건수를 자동 감사하는 `tools/audit_statutory_data_completeness.php`를 추가했다.
- 국민연금 최초 구간을 2012-07-01~2013-06-30으로 바로잡았다.
- 부가가치세 10% 최초 적용일을 1977-07-01로 바로잡고 제정법 Source로 교체했다.
- 2013년 산재보험 Source에 고용노동부 고시 원문 URL을 보강했다.
- 중간 감사에서 확인한 고용보험 2013-07 이후, 산재보험 2014 이후, 근로소득 간이세액표 2014-02-21 이후 공백은 아래 공식 원자료 확장 조사와 운영 반영으로 해소했다.
- Source는 해당 적용기간 기준행의 공식 근거자료이며 별도 Correction chain 객체를 사용하지 않는다. Source 수정은 현재 2테이블 계약 안에서 기존 Source ID와 생성 감사값을 보존하는 저장 경로를 사용한다.

## 완료 기준선

- 활성 Type은 13종, Standard는 91건, Source는 92건이다.
- 기간 감사 결과 13종 모두 중복 0건, 법적으로 존재하는 구간의 현재 Resolver 공백 0건이다. 법인지방소득세는 독립세 전환 전 기간을 의도적으로 생성하지 않는다.
- 근로소득 간이세액표는 2012-09-04, 2014-02-21, 2017-02-03, 2020-02-11, 2023-02-28의 실제 개정 구간 5건이다. 각 기간은 공제대상 가족수 1~11명, 전체 647행, 상한초과 규칙 2·2·3·5·6건을 보존한다. 2023 구간에는 8~20세 자녀 1명·2명·3명 이상 조정규칙 3건을 함께 저장한다.
- 고용보험은 2013-01-01, 2013-07-01, 2019-10-01, 2022-07-01의 4구간이다. 실업급여 근로자·사업주 부담률과 법령상 사업규모 4단계의 고용안정·직업능력개발사업 사업주 부담률을 분리한다.
- 산재보험 건설업은 2013~2026년 14개 연도 구간이다. 2018년 이후 `employer_rate`는 공식 고시의 사업종류별 요율과 전 업종 출퇴근재해 요율을 합한 실제 적용요율이다. 개별실적요율 등 사업장별 사후 가감은 이 공통 기준값에 혼합하지 않는다.
- Source 92건은 자료명·기관·법령명·URL·비고가 모두 입력되어 있다. 공포·고시번호 23건과 공표일 24건은 확인된 공식 메타데이터를 입력했다. 번호가 비어 있는 69건과 공표일이 비어 있는 68건은 법령 공포자료가 아니라 별도 번호·공표일 개념이 없는 공단·기관의 공식 안내·현황 페이지로 분류했으며, 법령 원문인데 번호나 공표일이 누락된 Source는 0건이다.
- 공식 XLS/PDF/HWP는 Matrix와 연도별 요율 검증에 사용했지만 사용자 승인 없는 영구 Storage 적재는 하지 않았다. 재현 가능한 정규화 결과는 `tools/data/statutory-income-tax-tables.json`에 보존한다.
